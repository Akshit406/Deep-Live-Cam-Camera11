# Start here

See [README.md](README.md) for one-command installation, running the app, both modes, and attribution.

- **Install.bat** installs the private runtime and Camera11.
- **Start Deep Live Cam.bat** runs the installed app.
- **Start Deep Live Cam (CPU).bat** runs with the CPU fallback.
- **Install Camera11.bat** repairs the device registration.
- **Uninstall Camera11.bat** removes this device's registration.

The full setup and troubleshooting guide is [docs/INSTALL.md](docs/INSTALL.md). Original Deep-Live-Cam credit and component notices are in [NOTICE.md](NOTICE.md).
